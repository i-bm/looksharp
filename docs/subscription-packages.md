# Subscription Packages - Looksharp Employer Plans

## Overview

Looksharp offers three subscription tiers designed to meet the needs of employers at different stages and sizes, from small startups to large enterprises. All plans include core features for posting opportunities and managing applicants, with increasing limits and premium features at higher tiers.

## Package Tiers

### 1. Free Tier
**Target Audience:** Small businesses, startups, organizations testing the platform

**Posting Limits:**
- 3 active opportunity postings at a time
- Unlimited total postings (can archive and create new ones)

**Core Features:**
- Basic company profile
- Opportunity posting (all types: Internship, Attachment, National Service, Graduate Trainee, Entry-level)
- Applicant management dashboard
- Basic applicant filtering
- Email notifications for new applications
- Application status tracking
- Basic analytics (views, applications count)

**Limitations:**
- No company branding customization
- No featured posting option
- No ATS integration
- Limited analytics
- Standard support only
- No priority in search results

**Business Rules:**
- Free tier is available to all verified employers
- No payment required
- No expiration date
- Can upgrade to paid tiers at any time
- When upgrading, active postings remain active

---

### 2. Starter Tier
**Target Audience:** Growing companies, mid-size businesses, regular recruiters

**Posting Limits:**
- 20 active opportunity postings at a time
- Unlimited total postings (can archive and create new ones)

**Core Features (includes all Free features plus):**
- Enhanced company branding:
  - Custom logo display
  - Company photos gallery (up to 10 photos)
  - Employee testimonials (up to 5)
  - Company video (up to 90 seconds)
  - Enhanced company description
- Featured posting option (additional fee per posting)
- Advanced applicant management:
  - Bulk actions (shortlist, reject, message)
  - Advanced filtering and search
  - Custom tags and notes
- Enhanced analytics:
  - Detailed applicant demographics
  - Application source tracking
  - Time-to-fill metrics
  - Export reports to CSV/Excel
- Interview scheduling:
  - Google Calendar integration
  - Outlook Calendar integration
  - Auto-timezone handling
  - Interview reminders
- Diversity & inclusion reporting:
  - Gender distribution
  - University/Institution breakdown
  - Regional distribution
- Priority email support (48-hour response)
- Priority placement in search results

**Limitations:**
- No ATS integration
- No API access
- Limited to 20 active postings
- Standard career fair participation

**Business Rules:**
- Monthly or annual billing available
- Annual billing includes 2 months free (17% discount)
- Auto-renewal enabled by default
- Can upgrade to Professional tier at any time
- Downgrade to Free tier only when active postings ≤ 3

---

### 3. Professional Tier
**Target Audience:** Large enterprises, high-volume recruiters, companies with ATS systems

**Posting Limits:**
- Unlimited active opportunity postings
- Unlimited total postings

**Core Features (includes all Starter features plus):**
- Unlimited active postings
- ATS (Applicant Tracking System) integration:
  - API access for custom integrations
  - Webhook support for real-time updates
  - Bulk candidate import/export
  - Sync with external ATS systems
- Advanced analytics and reporting:
  - Custom report builder
  - Scheduled reports
  - Advanced metrics and KPIs
  - ROI tracking
  - Talent pipeline analytics
- Enhanced applicant management:
  - AI-powered candidate matching
  - Automated screening workflows
  - Custom application forms
  - Video interview scheduling
- Offer letter management:
  - Template library
  - E-signature integration (HelloSign/DocuSign)
  - Offer tracking and acceptance
- Priority career fair participation:
  - Premium booth placement
  - Early access to career fair registration
  - Enhanced booth branding
- Dedicated account manager
- Priority support (24-hour response, phone support)
- White-label options (for enterprise clients)
- Custom integrations and API access

**Business Rules:**
- Monthly or annual billing available
- Annual billing includes 2 months free (17% discount)
- Auto-renewal enabled by default
- Can downgrade to Starter or Free tier
- Downgrade restrictions: Must reduce active postings to target tier limit before downgrade
- Enterprise pricing available for 50+ users

## Additional Services (Separate from Subscriptions)

### Featured Postings
- Boost individual postings to top of search results
- Enhanced visibility in opportunity feeds
- Pricing: GHS 50 per posting (7-day boost) or GHS 150 per posting (30-day boost)
- Available to Starter and Professional tiers
- Can purchase multiple featured postings

### Sponsored Career Fair Booths
- Premium booth placement at virtual career fairs
- Enhanced branding and visibility
- Pricing: GHS 500-2,000 per event (varies by event size)
- Available to all tiers (Professional tier gets priority access)

## Upgrade/Downgrade Policies

### Upgrading
- **Free → Starter/Professional:** Immediate activation upon payment
- **Starter → Professional:** Immediate activation, prorated billing for remaining days in current cycle
- Upgrades take effect immediately
- No data loss during upgrade

### Downgrading
- **Professional → Starter:** Allowed if active postings ≤ 20
- **Starter → Free:** Allowed if active postings ≤ 3
- **Professional → Free:** Allowed if active postings ≤ 3
- Downgrade takes effect at end of current billing cycle
- If active postings exceed target tier limit, employer must archive postings before downgrade
- No refunds for unused portion of current billing cycle (but can use until cycle ends)

### Cancellation
- Can cancel subscription at any time
- Access continues until end of current billing period
- No cancellation fees
- Can reactivate within 30 days without losing data

## Business Rules

### Subscription Management
1. All employers start on Free tier after verification
2. Subscription status is tied to employer company, not individual users
3. Multiple team members can access company account based on their role
4. Subscription limits apply to the entire company account
5. Active posting count includes all opportunity types (Internship, Attachment, National Service, Graduate Trainee, Entry-level)

### Payment & Billing
1. Payment required before paid tier activation
2. Monthly billing: Charged on same date each month
3. Annual billing: Charged on same date each year
4. Auto-renewal: Enabled by default, can be disabled
5. Payment failure: 7-day grace period, then downgrade to Free tier
6. Refunds: No refunds for partial periods, but access continues until period ends

### Posting Limits
1. "Active postings" = postings with status: Open, Pending, or Under Review
2. Archived/Closed postings don't count toward limit
3. When limit reached, must archive a posting before creating new one
4. Featured postings count toward active posting limit
5. National Service postings count toward active posting limit

### Verification Requirements
1. Free tier: Basic verification required (Ghana Card + Business Registration)
2. Starter tier: Same verification as Free
3. Professional tier: Enhanced verification may be required for enterprise features
